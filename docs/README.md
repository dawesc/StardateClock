# GitHub Pages for Stardate Clock

This `docs/` folder is ready for GitHub Pages.

## Enable Pages

1. Push this repository to GitHub.
2. In GitHub repo settings, open **Pages**.
3. Under **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/docs`
4. Save and wait for deployment.

## URLs to use in App Store Connect

- Marketing URL: `https://dawesc.github.io/StardateClock/`
- Support URL: `https://dawesc.github.io/StardateClock/support.html`
- Privacy Policy URL: `https://dawesc.github.io/StardateClock/privacy.html`

Replace placeholders with your actual username and repository name.
